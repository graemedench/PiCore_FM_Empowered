# Project structure and contributions

This public repository contains source, meaningful tests, installer/build tools, user documentation and hardware design files. Personal device settings, credentials, saved playlists, installation-session screenshots and detailed working logs are kept separately.

The installer remains a development preview pending complete clean-drive validation. Report the piCorePlayer version, hardware, reproduction steps and relevant logs with credentials removed. Do not include native pcp.cfg files, account tokens, private backup configuration or music files in issues or pull requests.

Keep public defaults independent of a particular account, IP address or remote identity. Preserve the original Sable/Quadify credits and included notices. All Git transfers use HTTPS. Build scripts fetch pinned upstream sources; generated archives and installed dependencies are excluded from Git.
