# FM4 rear Ethernet jack panel

This STL replaces the original rear IEC / **POWER OUT** outlet with an RJ45
Ethernet extension mounted behind a printed panel. It is a reversible,
no-drill conversion: the panel uses the original rectangular opening and its
existing top and bottom fixing points.

## Parts

Use a panel-mount RJ45 female-to-male Ethernet extension that fits this printed
panel, such as the [cable selected for this build](https://www.amazon.co.uk/gp/product/B07QPTTGMF/ref=ox_sc_act_title_1?smid=A3LDV8N4Y4AP0D&psc=1).

## Fitting

1. Disconnect the FM4 completely from mains power.
2. Have a suitably competent person confirm that the original mains hardware
   and wiring are safely isolated before removing the IEC / POWER OUT outlet.
3. Keep the original outlet and its screws in a labelled bag for a future
   return to original FM4 condition.
4. Fit the RJ45 extension to the printed panel, then secure the panel through
   the original top and bottom fixing holes. No drilling or chassis cutting is
   required.
5. Route the Ethernet lead internally without strain, sharp bends or contact
   with power components, then test the network connection before closing the
   chassis.

This is low-voltage network hardware, but its location replaces former mains
equipment. Do not leave any original mains wiring live, loose or exposed.
