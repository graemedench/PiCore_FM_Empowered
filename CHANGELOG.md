# Public project milestones

## Development preview — 8 October 2026

- Ported the Empowered Sable interface to piCorePlayer with OLED, encoder, buttons and IR controls.
- Added local Lyrion browsing, full playback queues, Favorites, source shortcuts and service URLs.
- Integrated native audio outputs, AirPlay, Wi-Fi, shutdown/wake and CD playback/ripping.
- Added live meters, spectrum, twin-needle displays and track-change overlays.
- Added Favorites web export and change-triggered three-slot backups with optional SMB upload.
- Included wiring, printable parts, design files, credits and source-build scripts.
- Public setup profile uses neutral defaults without personal TIDAL mix assignments.

The original working device has received functional testing. A clean installation is currently being restored manually to verify each step before completing a single-command installer. The scripted installer has isolated tests, but a complete fresh-drive installation is not yet verified. Bluetooth audio and IR pairing acceptance remain outstanding.

Detailed development notes, personal setup records and in-progress installation screenshots are maintained separately from this public repository.
