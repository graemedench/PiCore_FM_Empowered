# Hardware design sources and working parts

These current design files were copied from Graeme's local Quadify FM4 folder
on 4 October 2026. They supplement the released button/mounting packs. Original
Inventor files are retained where available; older automatic save versions and
superseded Legacy folders are left in the original local archive.

| Folder | Contents / status |
| --- | --- |
| Back Panel | Clamp CAD/STL and USB rear-panel inner/outer CAD/STLs; working fit/revision |
| Knob Adaptor | V6 long knob extender CAD/STL; matches released V6 concept |
| Knob Bracket | V4 encoder bracket CAD/STL |
| Network Port | Editable rear network panel CAD and printable STL |
| Screen Holder | V1 display holder CAD/STL and reference image |
| PCB Template Working | Rev A A4 1:1 test PDF; test template, not finished fabrication specification |

Use the released [FM4 Mounting Parts](../FM4%20Mounting%20Parts/README.md) and
[button pack](../FM4%20Button%20Print%20Pack/READ%20ME.txt) as the starting point.
For the template, print at actual size (100%, no fit-to-page) and verify its
scale and hole alignment before fabrication. Working USB/back-panel parts
need a fit check. Original project notices are retained in docs; no additional
commercial permission is implied. See [build notes](../docs/FM4-BUILD-NOTES.md).
