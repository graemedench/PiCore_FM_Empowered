# FM4 features and controls

Default Empowered controls (hold about 1.2 seconds):

| Button | Short press | Long press |
| --- | --- | --- |
| 1 | Play / pause, including restart after soft stop | Soft stop |
| 2 | Cycle stop-at-end / repeat one / repeat all / shuffle | No separate default |
| 3 | Previous track in queue | No separate default |
| 4 | Next track in queue | No separate default |
| 5 | BBC Radio 2 | Greatest Hits Radio |
| 6 | BBC Radio 4 | Absolute 80s |
| 7 | Assigned TIDAL mix/source | Second assigned mix/source |
| 8 | Save track to FM4 Favorites | Save current source as a shortcut |

The shortcut picker assigns button 5, 6 or 7, then Short press, Long press or
Cancel. Radio/mix assignments are editable; a new install needs your own mixes.
Turn the encoder for playback volume or menu navigation; press to open/select.
Use Back to leave menus. Apple IR provides menu/navigation/transport; Settings
includes remote capture/pairing.

Settings include display modes/brightness, audio output selection, Wi-Fi
join/status/IP, library scan/refresh, shortcuts, IR pairing and shutdown.
Service URLs > Web player shows the browser control address on the OLED,
alongside BBC Sounds/TIDAL sign-in and server settings addresses.

Sources include albums/artists/genres, playlists, queue, TIDAL, BBC Sounds and
radio shortcuts. An optical drive adds CD to the carousel. Selecting a track
retains its album/playlist/CD queue for skip controls. CD supports play, eject,
FLAC/MP3 rip and cancellation. Rips use artist/album folders, numbered titled
tracks and available metadata/art. Non-CD playback can continue during a rip;
CD playback stops to free the drive. The clock pie shows whole-disc progress.

Panel shows track details, elapsed / duration and stereo bars. Performance
omits bars. Panel / Needle VU, Panel / Twin Needle VU and Panel / Spectrum return to Panel
for five seconds after interaction. Track changes show centred title/artist
for four seconds on VU/Twin Needle and two seconds on Spectrum. Twin Needle VU has two needles in
each dial: bright fast level needle and a dimmer peak needle with a one-second hold then an eight-second full-scale decay, per channel.

AirPlay 2, Bluetooth, SMB and streaming accounts require native service setup.
See INSTALL.md. Physical test status is in FEATURE-MAP.md.
